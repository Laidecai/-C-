## 一、阅读程序写结果（标准答案解析）

### R03-01
- 题目：给定 i=2, j=3，执行 k = i++ + ++j; 输出 i, j, k。
- 标准答案：i=3, j=4, k=6
- 解析：i++ 先取值 2 后自增为 3；++j 先自增为 4 再参与运算。

### R03-02
- 题目：给定 int a=5; double b=2; printf("%.1f\n", a/b); 输出是什么？
- 标准答案：2.5
- 解析：a 在表达式中提升为 double，执行浮点除法。

### R03-03
- 题目：表达式 (x!=0) && (10/x>1) 在 x=0 时右侧是否执行？
- 标准答案：不执行
- 解析：&& 存在短路；左侧为假时右侧不求值。
