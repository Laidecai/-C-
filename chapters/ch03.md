## CH03-Q003
- **题目**：使用三目运算符实现两数较大值比较。
- **输入要求**：两个整数 a b
- **输出要求**：输出较大值
- **知识点**：Chapter 03 / 运算符与表达式
- **难度**：进阶

### 样例输入
```text
3 9
```

### 样例输出
```text
9
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int a,b;
    if (scanf("%d%d", &a, &b) != 2) return 1;
    int m = (a > b) ? a : b;
    printf("%d\n", m);
    return 0;
}
```

## CH03-Q005
- **题目**：编程验证 % 运算符在负数场景下的结果。
- **输入要求**：两个整数 a b（b!=0）
- **输出要求**：输出 a%b 的结果
- **知识点**：Chapter 03 / 运算符与表达式
- **难度**：挑战

### 样例输入
```text
-7 3
```

### 样例输出
```text
-1
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int a,b;
    if (scanf("%d%d", &a, &b) != 2 || b == 0) return 1;
    printf("%d\n", a % b);
    return 0;
}
```
