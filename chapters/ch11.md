## CH11-Q001
- **题目**：使用文本文件保存并读取学生成绩。
- **输入要求**：输入若干成绩记录
- **输出要求**：写入后再读取并输出
- **知识点**：Chapter 11 / 文件操作
- **难度**：基础

### 样例输入
```text
Tom 90
Ann 85
```

### 样例输出
```text
Tom 90
Ann 85
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    FILE *fp=fopen("scores.txt","w");
    if(!fp) return 1;
    fprintf(fp,"Tom 90\nAnn 85\n");
    fclose(fp);
    fp=fopen("scores.txt","r");
    if(!fp) return 1;
    char name[32]; int score;
    while(fscanf(fp,"%31s%d",name,&score)==2) printf("%s %d\n",name,score);
    fclose(fp);
    return 0;
}
```

## CH11-Q002
- **题目**：统计文本文件中的行数、单词数、字符数。
- **输入要求**：输入文件路径
- **输出要求**：输出行/词/字符统计
- **知识点**：Chapter 11 / 文件操作
- **难度**：基础

### 样例输入
```text
input.txt
```

### 样例输出
```text
line=10 word=58 char=320
```

### 参考答案模板（C）
```c
#include <stdio.h>
#include <ctype.h>

int main(void){
    char path[256];
    if(scanf("%255s",path)!=1) return 1;
    FILE *fp=fopen(path,"r");
    if(!fp) return 1;
    int c,lines=0,words=0,chars=0,inword=0;
    while((c=fgetc(fp))!=EOF){
        chars++;
        if(c=='\n') lines++;
        if(isspace(c)) inword=0;
        else if(!inword){ inword=1; words++; }
    }
    fclose(fp);
    printf("line=%d word=%d char=%d\n",lines,words,chars);
    return 0;
}
```
