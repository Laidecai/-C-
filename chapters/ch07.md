## CH07-Q001
- **题目**：编写 max(a,b) 与 swap(a,b)（指针版）。
- **输入要求**：输入两个整数 a b
- **输出要求**：输出 max 与交换后结果
- **知识点**：Chapter 07 / 函数
- **难度**：基础

### 样例输入
```text
3 8
```

### 样例输出
```text
max=8
swap: 8 3
```

### 参考答案模板（C）
```c
#include <stdio.h>

int max(int a,int b){ return a>b?a:b; }
void swap(int *a,int *b){ int t=*a;*a=*b;*b=t; }

int main(void){
    int a,b;
    if(scanf("%d%d",&a,&b)!=2) return 1;
    printf("max=%d\n",max(a,b));
    swap(&a,&b);
    printf("swap: %d %d\n",a,b);
    return 0;
}
```

## CH07-Q003
- **题目**：用递归与非递归分别实现斐波那契数列。
- **输入要求**：输入 n
- **输出要求**：输出第 n 项（从0开始）
- **知识点**：Chapter 07 / 函数
- **难度**：进阶

### 样例输入
```text
10
```

### 样例输出
```text
55
```

### 参考答案模板（C）
```c
#include <stdio.h>

long long fib_iter(int n){
    if(n<2) return n;
    long long a=0,b=1;
    for(int i=2;i<=n;i++){ long long c=a+b; a=b; b=c; }
    return b;
}

int main(void){
    int n;
    if(scanf("%d",&n)!=1 || n<0) return 1;
    printf("%lld\n", fib_iter(n));
    return 0;
}
```

## CH07-Q004
- **题目**：实现 is_prime(n) 并批量输出素数。
- **输入要求**：输入 n
- **输出要求**：输出 [2,n] 内素数
- **知识点**：Chapter 07 / 函数
- **难度**：进阶

### 样例输入
```text
10
```

### 样例输出
```text
2 3 5 7
```

### 参考答案模板（C）
```c
#include <stdio.h>

int is_prime(int n){
    if(n<2) return 0;
    for(int i=2;i*i<=n;i++) if(n%i==0) return 0;
    return 1;
}

int main(void){
    int n;
    if(scanf("%d",&n)!=1) return 1;
    for(int i=2;i<=n;i++) if(is_prime(i)) printf("%d ",i);
    putchar('\n');
    return 0;
}
```
