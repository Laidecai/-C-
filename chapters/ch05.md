## CH05-Q001
- **题目**：分别用 for/while/do-while 输出 1~100。
- **输入要求**：无
- **输出要求**：输出 1 到 100。
- **知识点**：Chapter 05 / 循环结构
- **难度**：基础

### 样例输入
```text
（无）
```

### 样例输出
```text
1 2 3 ... 100
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    for (int i=1; i<=100; i++) printf("%d%c", i, i==100?'\n':' ');
    return 0;
}
```

## CH05-Q002
- **题目**：计算 1! + 2! + ... + n!。
- **输入要求**：输入整数 n
- **输出要求**：输出阶乘和
- **知识点**：Chapter 05 / 循环结构
- **难度**：基础

### 样例输入
```text
4
```

### 样例输出
```text
33
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int n;
    if (scanf("%d", &n) != 1 || n < 1) return 1;
    long long fact=1, sum=0;
    for (int i=1; i<=n; i++){ fact *= i; sum += fact; }
    printf("%lld\n", sum);
    return 0;
}
```

## CH05-Q003
- **题目**：统计一段输入中数字字符个数。
- **输入要求**：输入一行字符串
- **输出要求**：输出数字字符个数
- **知识点**：Chapter 05 / 循环结构
- **难度**：进阶

### 样例输入
```text
a1b23
```

### 样例输出
```text
3
```

### 参考答案模板（C）
```c
#include <stdio.h>
#include <ctype.h>

int main(void){
    int c, cnt=0;
    while ((c=getchar()) != EOF && c!='\n') if (isdigit(c)) cnt++;
    printf("%d\n", cnt);
    return 0;
}
```

## CH05-Q004
- **题目**：输出九九乘法表。
- **输入要求**：无
- **输出要求**：按行输出 9x9 乘法表。
- **知识点**：Chapter 05 / 循环结构
- **难度**：进阶

### 样例输入
```text
（无）
```

### 样例输出
```text
1*1=1
1*2=2 2*2=4 ...
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    for (int i=1;i<=9;i++){
        for (int j=1;j<=i;j++) printf("%d*%d=%d%c", j,i,i*j, j==i?'\n':' ');
    }
    return 0;
}
```

## CH05-Q005
- **题目**：求 1000 以内所有水仙花数。
- **输入要求**：无
- **输出要求**：输出所有三位水仙花数。
- **知识点**：Chapter 05 / 循环结构
- **难度**：挑战

### 样例输入
```text
（无）
```

### 样例输出
```text
153 370 371 407
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    for (int n=100; n<1000; n++){
        int a=n/100,b=n/10%10,c=n%10;
        if (a*a*a+b*b*b+c*c*c==n) printf("%d ", n);
    }
    putchar('\n');
    return 0;
}
```
