## CH04-Q001
- **题目**：编程判断闰年。
- **输入要求**：输入年份 year
- **输出要求**：输出 Yes 或 No
- **知识点**：Chapter 04 / 顺序、分支结构
- **难度**：基础

### 样例输入
```text
2000
```

### 样例输出
```text
Yes
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int year;
    if (scanf("%d", &year) != 1) return 1;
    int leap = (year%400==0) || (year%4==0 && year%100!=0);
    printf("%s\n", leap ? "Yes" : "No");
    return 0;
}
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int score;
    if (scanf("%d", &score) != 1) return 1;
    if (score >= 90) puts("A");
    else if (score >= 80) puts("B");
    else if (score >= 70) puts("C");
    else if (score >= 60) puts("D");
    else puts("E");
    return 0;
}
```

## CH04-Q003
- **题目**：用 switch 实现简易计算器（+ - * /）。
- **输入要求**：输入：a op b
- **输出要求**：输出：运算结果或错误提示
- **知识点**：Chapter 04 / 顺序、分支结构
- **难度**：进阶

### 样例输入
```text
8 * 7
```

### 样例输出
```text
56
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    double a,b; char op;
    if (scanf("%lf %c %lf", &a, &op, &b) != 3) return 1;
    switch(op){
        case '+': printf("%.2f\n", a+b); break;
        case '-': printf("%.2f\n", a-b); break;
        case '*': printf("%.2f\n", a*b); break;
        case '/': if (b==0) puts("Error"); else printf("%.2f\n", a/b); break;
        default: puts("Error");
    }
    return 0;
}
```
