## CH09-Q001
- **题目**：不使用库函数实现 strcpy。
- **输入要求**：输入源字符串（不含空格）
- **输出要求**：输出拷贝后的字符串
- **知识点**：Chapter 09 / 字符串
- **难度**：基础

### 样例输入
```text
world
```

### 样例输出
```text
world
```

### 参考答案模板（C）
```c
#include <stdio.h>

char* my_strcpy(char *dst, const char *src){
    char *ret=dst;
    while((*dst++=*src++));
    return ret;
}

int main(void){
    char src[1000], dst[1000];
    if(scanf("%999s",src)!=1) return 1;
    my_strcpy(dst,src);
    puts(dst);
    return 0;
}
```

## CH09-Q002
- **题目**：不使用库函数实现 strcmp。
- **输入要求**：输入两个字符串（不含空格）
- **输出要求**：输出比较结果（负/零/正）
- **知识点**：Chapter 09 / 字符串
- **难度**：基础

### 样例输入
```text
abc abd
```

### 样例输出
```text
-1
```

### 参考答案模板（C）
```c
#include <stdio.h>

int my_strcmp(const char *a,const char *b){
    while(*a && *a==*b){a++;b++;}
    return (unsigned char)*a - (unsigned char)*b;
}

int main(void){
    char a[1000],b[1000];
    if(scanf("%999s%999s",a,b)!=2) return 1;
    int r=my_strcmp(a,b);
    if(r<0) puts("-1");
    else if(r>0) puts("1");
    else puts("0");
    return 0;
}
```

## CH09-Q003
- **题目**：实现字符串逆序。
- **输入要求**：输入字符串（不含空格）
- **输出要求**：输出逆序字符串
- **知识点**：Chapter 09 / 字符串
- **难度**：进阶

### 样例输入
```text
abcd
```

### 样例输出
```text
dcba
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    char s[1000];
    if(scanf("%999s",s)!=1) return 1;
    int n=0; while(s[n]) n++;
    for(int i=n-1;i>=0;i--) putchar(s[i]);
    putchar('\n');
    return 0;
}
```

## CH09-Q004
- **题目**：统计字符串中各类字符（字母/数字/空格/其他）。
- **输入要求**：输入一行文本
- **输出要求**：输出四类字符计数
- **知识点**：Chapter 09 / 字符串
- **难度**：进阶

### 样例输入
```text
ab 12?!
```

### 样例输出
```text
alpha=2 digit=2 space=1 other=2
```

### 参考答案模板（C）
```c
#include <stdio.h>
#include <ctype.h>

int main(void){
    int c,a=0,d=0,s=0,o=0;
    while((c=getchar())!=EOF && c!='\n'){
        if(isalpha(c)) a++;
        else if(isdigit(c)) d++;
        else if(isspace(c)) s++;
        else o++;
    }
    printf("alpha=%d digit=%d space=%d other=%d\n",a,d,s,o);
    return 0;
}
```

## CH09-Q005
- **题目**：判断一个字符串是否为回文串。
- **输入要求**：输入字符串（不含空格）
- **输出要求**：输出 Yes 或 No
- **知识点**：Chapter 09 / 字符串
- **难度**：挑战

### 样例输入
```text
level
```

### 样例输出
```text
Yes
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    char s[1000];
    if(scanf("%999s",s)!=1) return 1;
    int n=0; while(s[n]) n++;
    int ok=1;
    for(int i=0,j=n-1;i<j;i++,j--) if(s[i]!=s[j]){ok=0;break;}
    puts(ok?"Yes":"No");
    return 0;
}
```
