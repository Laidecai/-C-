## CH02-Q005
- **题目**：设计一个摄氏度转华氏度的小程序。
- **输入要求**：一个浮点数 c（摄氏度）
- **输出要求**：输出华氏温度 f
- **知识点**：Chapter 02 / 基本数据类型、常量与变量
- **难度**：挑战

### 样例输入
```text
25
```

### 样例输出
```text
77.00
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void) {
    double c;
    if (scanf("%lf", &c) != 1) return 1;
    double f = c * 9.0 / 5.0 + 32.0;
    printf("%.2f\n", f);
    return 0;
}
```
