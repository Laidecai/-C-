## CH08-Q002
- **题目**：编写函数交换两个变量（必须使用指针）。
- **输入要求**：输入两个整数
- **输出要求**：输出交换后的两个值
- **知识点**：Chapter 08 / 指针
- **难度**：基础

### 样例输入
```text
10 20
```

### 样例输出
```text
20 10
```

### 参考答案模板（C）
```c
#include <stdio.h>

void swap(int *a,int *b){ int t=*a;*a=*b;*b=t; }

int main(void){
    int a,b;
    if(scanf("%d%d",&a,&b)!=2) return 1;
    swap(&a,&b);
    printf("%d %d\n",a,b);
    return 0;
}
```

## CH08-Q003
- **题目**：用指针遍历数组并求和。
- **输入要求**：输入 n 和 n 个整数
- **输出要求**：输出总和
- **知识点**：Chapter 08 / 指针
- **难度**：进阶

### 样例输入
```text
5
1 2 3 4 5
```

### 样例输出
```text
15
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int n;
    if(scanf("%d",&n)!=1 || n<=0 || n>1000) return 1;
    int a[1000];
    for(int i=0;i<n;i++) scanf("%d",&a[i]);
    long long sum=0;
    for(int *p=a; p<a+n; p++) sum += *p;
    printf("%lld\n",sum);
    return 0;
}
```

## CH08-Q004
- **题目**：实现字符串长度函数（不使用 strlen）。
- **输入要求**：输入字符串（不含空格）
- **输出要求**：输出长度
- **知识点**：Chapter 08 / 指针
- **难度**：进阶

### 样例输入
```text
hello
```

### 样例输出
```text
5
```

### 参考答案模板（C）
```c
#include <stdio.h>

size_t my_strlen(const char *s){
    const char *p=s;
    while(*p) p++;
    return (size_t)(p-s);
}

int main(void){
    char s[1000];
    if(scanf("%999s",s)!=1) return 1;
    printf("%zu\n",my_strlen(s));
    return 0;
}
```
