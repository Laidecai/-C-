## CH06-Q001
- **题目**：读取 10 个整数并求最大值最小值。
- **输入要求**：输入10个整数
- **输出要求**：输出最大值和最小值
- **知识点**：Chapter 06 / 数组
- **难度**：基础

### 样例输入
```text
3 5 -2 8 0 4 7 6 1 9
```

### 样例输出
```text
max=9 min=-2
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int a[10];
    for(int i=0;i<10;i++) if(scanf("%d",&a[i])!=1) return 1;
    int mn=a[0],mx=a[0];
    for(int i=1;i<10;i++){ if(a[i]<mn) mn=a[i]; if(a[i]>mx) mx=a[i]; }
    printf("max=%d min=%d\n", mx, mn);
    return 0;
}
```

## CH06-Q002
- **题目**：实现冒泡排序并分析时间复杂度。
- **输入要求**：输入 n 和 n 个整数
- **输出要求**：输出升序结果
- **知识点**：Chapter 06 / 数组
- **难度**：基础

### 样例输入
```text
5
5 2 4 1 3
```

### 样例输出
```text
1 2 3 4 5
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int n;
    if(scanf("%d",&n)!=1 || n<=0 || n>1000) return 1;
    int a[1000];
    for(int i=0;i<n;i++) scanf("%d",&a[i]);
    for(int i=0;i<n-1;i++) for(int j=0;j<n-1-i;j++) if(a[j]>a[j+1]){int t=a[j];a[j]=a[j+1];a[j+1]=t;}
    for(int i=0;i<n;i++) printf("%d%c",a[i],i==n-1?'\n':' ');
    return 0;
}
```

## CH06-Q003
- **题目**：实现二分查找并说明前提条件。
- **输入要求**：输入有序数组与目标值
- **输出要求**：输出目标下标或 -1
- **知识点**：Chapter 06 / 数组
- **难度**：进阶

### 样例输入
```text
5
1 3 5 7 9
7
```

### 样例输出
```text
3
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int n,x;
    if(scanf("%d",&n)!=1 || n<=0 || n>1000) return 1;
    int a[1000];
    for(int i=0;i<n;i++) scanf("%d",&a[i]);
    scanf("%d",&x);
    int l=0,r=n-1,ans=-1;
    while(l<=r){
        int m=l+(r-l)/2;
        if(a[m]==x){ans=m;break;}
        if(a[m]<x) l=m+1; else r=m-1;
    }
    printf("%d\n",ans);
    return 0;
}
```

## CH06-Q004
- **题目**：统计一组成绩的均值、方差。
- **输入要求**：输入 n 和 n 个成绩
- **输出要求**：输出均值与方差
- **知识点**：Chapter 06 / 数组
- **难度**：进阶

### 样例输入
```text
4
80 90 70 60
```

### 样例输出
```text
mean=75.00 var=125.00
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int n;
    if(scanf("%d",&n)!=1 || n<=0 || n>1000) return 1;
    double a[1000],sum=0;
    for(int i=0;i<n;i++){ scanf("%lf",&a[i]); sum+=a[i]; }
    double mean=sum/n,var=0;
    for(int i=0;i<n;i++){ double d=a[i]-mean; var+=d*d; }
    var/=n;
    printf("mean=%.2f var=%.2f\n",mean,var);
    return 0;
}
```

## CH06-Q005
- **题目**：将一个数组循环右移 k 位。
- **输入要求**：输入 n、数组和 k
- **输出要求**：输出右移后的数组
- **知识点**：Chapter 06 / 数组
- **难度**：挑战

### 样例输入
```text
5
1 2 3 4 5
2
```

### 样例输出
```text
4 5 1 2 3
```

### 参考答案模板（C）
```c
#include <stdio.h>

int main(void){
    int n,k;
    if(scanf("%d",&n)!=1 || n<=0 || n>1000) return 1;
    int a[1000],b[1000];
    for(int i=0;i<n;i++) scanf("%d",&a[i]);
    scanf("%d",&k);
    k=((k%n)+n)%n;
    for(int i=0;i<n;i++) b[(i+k)%n]=a[i];
    for(int i=0;i<n;i++) printf("%d%c",b[i],i==n-1?'\n':' ');
    return 0;
}
```
