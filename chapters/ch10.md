## CH10-Q001
- **题目**：定义学生结构体并完成成绩录入与排序。
- **输入要求**：输入 n 和 n 条学生信息
- **输出要求**：按成绩排序后输出
- **知识点**：Chapter 10 / 结构体与共用体
- **难度**：基础

### 样例输入
```text
3
Tom 80
Ann 95
Bob 88
```

### 样例输出
```text
Ann 95
Bob 88
Tom 80
```

### 参考答案模板（C）
```c
#include <stdio.h>

typedef struct { char name[32]; int score; } Student;

int main(void){
    int n;
    if(scanf("%d",&n)!=1 || n<=0 || n>200) return 1;
    Student s[200];
    for(int i=0;i<n;i++) scanf("%31s%d",s[i].name,&s[i].score);
    for(int i=0;i<n-1;i++) for(int j=0;j<n-1-i;j++) if(s[j].score<s[j+1].score){Student t=s[j];s[j]=s[j+1];s[j+1]=t;}
    for(int i=0;i<n;i++) printf("%s %d\n",s[i].name,s[i].score);
    return 0;
}
```
