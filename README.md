# 中国大学计算机门类《C 语言程序设计》课后习题库（合规版）

本仓库用于建设 **C 语言课程习题库框架**，面向中国大学计算机相关专业课程使用。

## 合规说明

- 本仓库**不直接收录受版权保护教材的全文和原版课后题原文**。
- 本仓库提供：
  1. 可公开获取或可合法购买的教材清单；
  2. 按知识点组织的练习题库（原创/改写题）；
  3. 题库扩展规范，便于后续补充。

## 二、课程知识点与练习题库

以下题目按高校常见教学章节组织，可直接作为课后作业、实验或复习题库。

### Chapter 01 程序设计基础与开发环境

1. 解释编译、链接、运行三个阶段的区别。
2. 编写第一个 `Hello, World!` 程序并说明每一行作用。
3. 比较 `int main(void)` 与 `int main(int argc, char *argv[])`。
4. 给出 3 个常见编译错误并说明如何定位。
5. 用命令行完成“编译 + 运行 + 重定向输出”。

### Chapter 02 基本数据类型、常量与变量

1. 说明 `char`、`int`、`float`、`double` 的典型取值范围。
2. 比较 `const` 常量与宏常量的差异。
3. 编写程序输出各基本类型占用字节数。
4. 分析整型溢出示例并解释原因。
5. 设计一个摄氏度转华氏度的小程序。

### Chapter 03 运算符与表达式

1. 说明前置/后置自增的求值差异。
2. 给出表达式类型提升的 3 个示例。
3. 使用三目运算符实现两数较大值比较。
4. 分析短路求值在逻辑运算中的作用。
5. 编程验证 `%` 运算符在负数场景下的结果。

### Chapter 04 顺序、分支结构

1. 编程判断闰年。
2. 用 `if-else` 实现成绩等级转换。
3. 用 `switch` 实现简易计算器（+ - * /）。
4. 比较 `if-else-if` 与 `switch` 的适用场景。
5. 实现输入三边判断能否构成三角形。

### Chapter 05 循环结构

1. 分别用 `for/while/do-while` 输出 1~100。
2. 计算 `1! + 2! + ... + n!`。
3. 统计一段输入中数字字符个数。
4. 输出九九乘法表。
5. 求 1000 以内所有水仙花数。

### Chapter 06 数组

1. 读取 10 个整数并求最大值最小值。
2. 实现冒泡排序并分析时间复杂度。
3. 实现二分查找并说明前提条件。
4. 统计一组成绩的均值、方差。
5. 将一个数组循环右移 `k` 位。

### Chapter 07 函数

1. 编写 `max(a,b)` 与 `swap(a,b)`（指针版）。
2. 比较值传递与“地址传递”效果。
3. 用递归与非递归分别实现斐波那契数列。
4. 实现 `is_prime(n)` 并批量输出素数。
5. 设计“菜单驱动”程序并拆分为多个函数。

### Chapter 08 指针

1. 解释“指针变量”和“被指向的变量”的区别。
2. 编写函数交换两个变量（必须使用指针）。
3. 用指针遍历数组并求和。
4. 实现字符串长度函数（不使用 `strlen`）。
5. 分析野指针、悬空指针的成因与规避方法。

### Chapter 09 字符串

1. 不使用库函数实现 `strcpy`。
2. 不使用库函数实现 `strcmp`。
3. 实现字符串逆序。
4. 统计字符串中各类字符（字母/数字/空格/其他）。
5. 判断一个字符串是否为回文串。

### Chapter 10 结构体与共用体

1. 定义学生结构体并完成成绩录入与排序。
2. 比较结构体数组与数组结构体访问方式。
3. 使用结构体指针操作链式数据。
4. 解释共用体的内存共享特征。
5. 设计“图书信息管理”基础结构。

### Chapter 11 文件操作

1. 使用文本文件保存并读取学生成绩。
2. 统计文本文件中的行数、单词数、字符数。
3. 实现二进制文件写入与读取结构体。
4. 比较 `fgets`/`fscanf` 的差异与风险。
5. 给出文件读写错误处理方案。

### Chapter 12 综合实践

1. 学生成绩管理系统（增删改查、排序、持久化）。
2. 通讯录管理系统（结构体 + 文件）。
3. 简易词频统计器（字符串 + 文件）。
4. 迷你计算器（表达式与异常输入处理）。
5. 小型题库系统（随机出题、评分、错题记录）。

## 三、题库扩展规范

新增题目建议遵循：

- 题号格式：`CHxx-Qyyy`
- 每题字段：题目、输入要求、输出要求、样例、知识点、难度、参考解法
- 难度分级：`基础 / 进阶 / 挑战`
- 优先补充：与教材章节一一对应的“知识点覆盖题”
